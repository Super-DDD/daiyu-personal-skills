# Implement

依据用户提供的要求、模型或方案，完成本轮约定的实现、应用或练习。关键方案已确定，且用户已授权本轮实施时，可以开始动手。分别核对这两项，沿用仍适用的确认和授权。

1. 核对目标、边界和完成条件，明确当前做法与必要的执行步骤。缺少会影响实施的关键输入、方案决定或授权时，说明缺口并等待。需要用户决定时，先用用户熟悉的概念补足判断所需的背景，再说明各可行做法的取舍、风险、回退成本和推荐依据。理解上的疑点会影响决定时，请用户解释或预测一个具体情境，发现误解先澄清。
2. 在授权范围内推进。实现任务先打通能呈现约定结果的最小链路，按需要补足逻辑。学习或实践时，按用户目标选择讲解、示范、推演或练习。目标包含掌握能力时，以用户实际解释、预测或尝试的表现判断进度。边学边做时，让用户用正在做的任务应用刚理解的概念，观察实际结果。
3. 对照本轮完成条件查看实际产物或练习结果，复用仍适用的证据。交付结果，说明实际做成了什么、观察到什么，以及仍待处理的事项，然后结束本环节。

遇到需要用户决定的取舍或需要选择检查依据时，参照[共用原则与个人偏好](../learn-or-do/preferences.md)中的「决策与自主推进」和「实施与证据」。任务已有约定的记录位置时，按[记录与接续](../learn-or-do/preferences.md#记录与接续)更新。
