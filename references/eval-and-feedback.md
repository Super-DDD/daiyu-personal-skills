# 样本评估与反馈

提取实践样本、评估目标 Skill 或根据反馈迭代时使用。目标是让用户能判断 Skill 是否好用、哪里值得改，而不是阅读大量产物后只能笼统认可。

## 1. 从实践中提取样本

样本可来自两类过程：未使用 Skill 时完成的一次满意实践；或使用初版 Skill 后，经交流和修正最终达标的实践。前者可帮助构想初版，后者可用于修复与回归。都要由用户审核，不能把 Agent 自拟的成功案例当作用户认可的经验。

从已有材料和实际对话提取，保留以下内容：

- **输入 X：**背景、意图、目标、预期和约束，以及实际提供的材料。区分初始输入和交流中才澄清的信息。
- **参考结果 Y：**用户认可的产物或目标达成状态，以及认可范围和依据。Y 是参考，不是唯一正确答案。
- **主要过程：**影响结果的关键交互、选择、修正和注意事项。区分可复用经验、个人偏好与未经验证的解释；保留重要的失败与纠正，不将其写成推荐步骤。
- **判据与来源：**对照用户认可的目标、预期、约束和验收条件判断是否达标，再看概念是否连贯、复杂性是否必要。判据关联原要求或用户确认，不以篇幅、措辞相似度代替质量。

先交给用户 Review，确认样本能代表其思路、参考结果至少达到认可标准，再用于对比评估。可单独调用本过程提取样本，不必立即生成或修改 Skill。

没有真实样本时，可按约定先形成 V0，在实际使用中积累；若先做假设案例检查，标明它只能支持初步判断。资料或对话不完整时注明缺口，不补造用户认可、原始记录或验证结果。

## 2. 按实际用途运行

与用户对齐本轮范围、输入、预期和参与方式，确定何时结束。可以只测一个关键环节；明确未覆盖的内容，不为复现历史而强迫走完流程。

- **交互型任务：**让使用待测 Skill 的 Agent 与真实用户交流，用户根据当下理解作答。可由主会话直接执行，也可由独立执行者运行、主会话原样转达；不得替用户回答。用户决定试用足够时结束。
- **可独立完成的任务：**可由 Agent 在已确认条件下执行，检查产物与可观察行为。模拟交互只能作为明确标注的辅助检查，不替代真人体验证据。

向执行者提供待测 Skill、选定输入和必要任务条件；参考 Y、历史后续纠正与评估结论留给评估者。任务本来需要参考产物时可以提供，但注明条件，不声称是未见答案的重跑。

执行者上下文已包含参考 Y 或历史后续纠正时，改用未接触这些材料的独立执行上下文；无法隔离时，标明是已知参考条件下的试用，不作未见答案的重跑。

保存待测版本、本轮实际输入、用户新增反馈、输出和关键动作。试验产物与正式文件隔离，不覆盖参考样本。记录范围或条件变化；例如只做方案讨论、用户已熟悉旧结果，都影响可比性。

## 3. 比较、归因与改进

先按本轮适用判据判断达标、部分达标、未达标或证据不足，再提炼最影响用户目标的差异。只比较可比部分；某环节未运行，不等于通过或失败。

交互型任务同时看协作过程与结果：建议是否容易理解，是否获取并尊重真实反馈，用户能否影响关键取舍，以及结果是否满足目标。不要机械比较轮数、照抄历史问答或把不同的有效方案判错。

每项关键发现说明：**差异 → 对目标的影响 → 证据 → 可能原因 → 调整建议**。引用少量原文并定位记录；区分输入、用户参与、Skill 指导、执行和环境等因素。没有对照验证时，原因是待验证的解释，不将差异直接归因于 Skill，不强行给一个总分或 loss。

建议尽量具体、局部且有证据。让用户决定是否修改；按已有授权实施后，针对问题复验，保留修改前后的版本与结果。不以反复重跑直到成功掩盖失败。已用于调整的样本主要支持调试与回归，后续增加新样本检查适用范围。

## 4. 让用户先读主报告

默认采用以下结构，原始材料按需附在证据目录中，不拆出大量平级说明文件：

```text
本次评估/
├── 主报告.md
└── 证据/
    ├── 参考样本.md
    ├── 本轮运行记录.md
    ├── 详细对比分析.md
    └── 原始材料/        有需要时保存原始文件、消息与可观察日志
```

**主报告**简洁给出总体判断、最值得 Review 的差异、原因与把握、调整建议及必要限制。说明用户需要决定什么；若结果足够好，也可建议不改。附证据链接和阅读说明，默认不要求用户通读附件。

**参考样本**与**本轮运行记录**均按“任务条件—输入—主要过程—输出—已知限制”组织，便于在 IDE 并排阅读。保存完整输入、相关输出和主要交互；大文件或重复材料可链接至原样副本，避免重复粘贴。标明原文、摘要和整理者，不将过程概括冒称完整会话。

**详细对比分析**保存逐项判据、具体证据、归因依据、其他可能解释和建议，供用户有疑问时核查。这里记录可核查的分析，不要求导出模型内部推理。

### 样本记录简表

```text
任务与范围：
输入 X：初始条件、材料及后续澄清
参考 Y：完整结果或原样文件链接、用户认可范围
主要过程：关键交互、选择、修正及来源
评价判据：目标与约束、概念连贯性、必要复杂性
审核与限制：用户意见、版本、记录缺口
```

### 主报告简表

```text
本轮范围与总体判断：哪些已验证，哪些未覆盖
关键差异：差异、影响、证据、可能原因、调整建议
用户决策：接受、不改或确认哪些修改
证据入口与限制：参考样本、本轮记录、详细分析
```

样本与评估报告保存在任务目录，不默认打包进目标 Skill。Skill 中沉淀可复用的方法和必要资源；原始对话、单次产物与调试记录按需查阅。
