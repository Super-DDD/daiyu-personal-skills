# Intent

对齐用户为什么提出当前问题、处在什么情境，以及希望弄清或改变什么。输入可以是一个初步想法、一段现有材料或用户对目标的说明。

1. **先查背景，形成初步理解。** 从用户的原话和已有共识出发，沿着具体线索查相关材料。比如用户说“以前更好用”，就对照新旧版本，找出同一个场景里行为发生了什么变化。区分已核实的事实、用户表达的感受或目的，以及你对原因的推测。
2. **带着依据问。** 用一两句话说清你看到了什么，再问当前最影响理解、需要用户补充的那个问题。优先问后续讨论所依赖的事。动机还模糊时，可请用户回忆一次具体经历：当时想做什么，实际发生了什么，原本期待怎样？有几种合理解释时，说清它们在这个场景里有什么区别，给用户纠正或提出另一种解释的空间。
3. **顺着回答继续挖。** 等用户回答，再决定下一步。回答带来可核实的新线索时，先去查；回答改变了原先的判断时，简短说清理解变在哪里。沿仍会影响意图的疑点继续追问，复用已经说清的部分。双方反复说不拢时，回到具体场景核对用词、事实和各自在意的结果。
4. **确认共同理解。** 当你能用用户认可的语言说清事情发生的背景、为什么值得关注，以及用户希望弄清或改变什么，就把这段理解交给用户确认。若有纠正，更新受影响的部分；用户已明确认可这段表述时即可收束。

本次调用以澄清意图为边界。把涉及范围、规格、模型或实施的待定事项交还给用户，由用户另行选择下一步。

需要判断从什么概念讲起时，参照[查证与提问](../learn-or-do/preferences.md#查证与提问)。任务已有约定的记录位置时，按[记录与接续](../learn-or-do/preferences.md#记录与接续)更新。
