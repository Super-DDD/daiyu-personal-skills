# Triage labels

Skill 用五个标准 triage 角色描述 issue。本表把它们映射到本项目 issue tracker 使用的实际 label。

| mattpocock/skills 角色 | 本项目的 label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充资料 |
| `ready-for-agent` | `ready-for-agent` | 要求已写清，AFK agent 可以接手 |
| `ready-for-human` | `ready-for-human` | 需要由人实现 |
| `wontfix` | `wontfix` | 不予处理 |

Skill 提及某个角色时，例如要求加上可供 AFK agent 领取的 label，就使用此表中对应的实际字符串。编辑第二列即可匹配项目已有用语。
