# implement

实现用户在 spec 或 ticket 中描述的工作。

如果用户传来 ticket 引用，从 issue tracker 获取它，在开工前说出标题。引用有歧义时询问用户。

尽可能在事先约定的 seam 上调用 [tdd](../tdd/SKILL.md)。

经常运行 typecheck 和单个测试文件，最后跑一次完整的 test suite。

完成后带上本轮变更范围和对应 spec，使用 [code-review](../code-review/SKILL.md) 审查改动。

把工作提交到当前 branch。
