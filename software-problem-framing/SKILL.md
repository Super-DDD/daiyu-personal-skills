# 明确问题与价值

- **思考：**为什么做？为谁做？解决什么问题？如何判断有效？

围绕一个业务问题、新项目或已有系统建立背景。输入可以是初步想法、访谈记录、业务资料或用户指出的现状问题。复用仍适用的材料和已确认的范围。

1. **了解现实业务。** 阅读材料、访谈或观察实际工作，梳理业务概况、现状和主要问题。从证据说明问题在什么情境下发生、影响谁。
2. **分析涉众。** 识别相关角色，梳理职责、诉求、优先级和可能的利益冲突。把有影响的分歧交给可以作决定的人。
3. **明确目标与成功标准。** 说明本轮先解决什么、负责到哪里、有哪些约束。对每个优先问题，说明谁在什么情境下会看到什么改善。有现状数据时写出基线，缺少数据时说明准备观察什么。优先查证会改变价值、范围或可行性判断的未知项，可查现有方案、调研，或在约定范围内做小规模探索。记录仍待确定的风险和初步安排。
4.**可行性分析。** 进行充分调研，从如业务、技术、时间与资源等方面判断项目能否实施、是否值得实施，并识别主要风险。参考市场已有产品、方案、思想。

- **结果：**业务概况、涉众及其诉求、主要目标与优先级、范围、约束、成功标准、风险与初步计划，足以说明本轮为什么做、为谁做、先解决什么、负责到哪里。


任务已有约定的记录位置时，按[记录与接续](../learn-or-do/preferences.md#记录与接续)同步结果。结束本环节后，用户可将说明作为需求与业务分析的输入。
