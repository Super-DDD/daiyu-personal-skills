# Modeling 图示偏好

| 用户想弄清的问题 | 选图与画法 |
| --- | --- |
| 从触发到结束，经过哪些主要步骤？ | 先画活动图，用业务动作串起主流程，标出影响走向的分支条件。 |
| 涉及哪些外部系统，它们怎样交互？ | 画简要架构图，标出当前系统、外部系统和它们交换的请求或数据。 |
| 各方负责哪块业务，怎样协作？ | 画业务上下文映射图，标明各业务上下文的职责和协作关系。 |
| 对象怎样组成，谁持有状态、依赖谁？ | 画类图，保留解释问题所需的类、关键状态和关系。 |
| 一个对象在生命周期中会经历哪些状态？什么会触发状态转换？ | 画状态图，用节点表示状态，用有向箭头表示允许的转换，在箭头上标明触发事件和必要条件。 |
| 在一次具体场景里，谁先调用谁，结果怎样返回？ | 画时序图，沿该场景标出参与者、调用顺序和关键返回结果。 |

支持 Mermaid 时优先使用 Mermaid。同一对象用多张图展开时，沿用前图中的角色名、对象名或步骤名，让读者知道后图展开了哪一部分。
